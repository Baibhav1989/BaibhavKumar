# Portfolio (HTML)

This is a simple, responsive portfolio UI generated from your resume content.

## Files

- `index.html`: page structure and content
- `video-portfolio.html`: video portfolio page (add your demo videos/links here)
- `styles.css`: styling (no frameworks)
- `script.js`: theme toggle + current year

## Run locally

Option 1: open `index.html` directly in a browser.

Option 2 (recommended): run a small local server:

```bash
cd "/Users/baibhav.kumar/Documents/Myself" && python3 -m http.server 5173
```

Then open `http://localhost:5173` in your browser.

## Add your resume

Place your resume as `resume.pdf` in this folder so the “Resume (PDF)” button works:

- `./resume.pdf`
